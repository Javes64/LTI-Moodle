# Moodle LTI Setup


# Installation

Install the required Python dependencies:

`pip install -r requirements.txt`

---

# Expose the Local Server with ngrok

Since Moodle needs to access your local development server, expose it using ngrok:

`ngrok http 5000`

ngrok will generate a public HTTPS URL similar to this:

`https://abcd-1234.ngrok-free.app`


---

# Start the Application

Run the Flask application:

`python app.py`


---

# Adding the Tool to Moodle

In Moodle, navigate to the **External Tool** configuration page and create a new LTI 1.3 tool.

Use the following section in Moodle:

![](docs/Screenshot%202026-05-29%20173624.png)

---

## Required URLs

Replace `YOUR_NGROK_URL` with the HTTPS URL generated by ngrok.

| Setting            | Value                            |
| ------------------ | -------------------------------- |
| Tool URL           | `https://YOUR_NGROK_URL/launch/` |
| Initiate Login URL | `https://YOUR_NGROK_URL/login/`  |
| Redirection URL    | `https://YOUR_NGROK_URL/launch/` |

## Important Configuration

Make sure that:

* **LTI 1.3** is selected
* The tool visibility and deployment settings are configured correctly

# Client ID Configuration

After creating the tool, Moodle will generate a **Client ID**.

Copy this value and paste it into the `client_id` field inside:

```text
tool.json
```
